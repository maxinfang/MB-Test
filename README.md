# Markbridge Jewellers — MB Test

A luxury jewelry store homepage generated with [Google Stitch](https://stitch.google.com).

## Quick Start

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000)

## Stack

- **Design**: Generated via Stitch MCP (Project ID: `3312579727973105822`)
- **Hosting**: Vercel
- **Theme**: Dark luxury, gold (#C9A96E) accents, Manrope font

## Stitch Skills Used

- `generate_screen_from_text` — Initial homepage generation
